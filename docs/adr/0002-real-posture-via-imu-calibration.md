# ADR-0002: 真姿态分类——IMU 重力方向 + 固定轴阈值

## 状态

已接受（2026-09-07），作废 ADR-0001（motion_mean 代理姿态）。

## 背景

ADR-0001 前提「无方向数据」错误：IMU accel 三分量可由重力方向判姿态。
硬件定型：固定左脚佩戴且结构锁死朝向 → 轴向映射唯一，校准制不需要。

## 决策

1. 包加 accel_x/y/z_mean（5s 窗均值）；sensor_data 加同名列；gyro 三分量不进包。
2. 分类规则（FeatureService，3 常量：主导轴/符号/阈值，假设 z 轴仰卧 -1g，硬件到位改常量重编）：motion≥0.15→3活动；az<-0.5→0仰卧；az>+0.5→2俯卧；否则→1侧卧。
3. 软兼容：老固件无三分量→posture NaN，模型 1.5.0 仍可用；新固件走 OTA。

## 后果

契约升 1.5.0（posture_code 0-3，仍 15 维）；字典二次修订；模拟器/seed/e2e 同步。
