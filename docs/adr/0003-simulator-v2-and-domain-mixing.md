# ADR-0003: 下一阶段训练策略——模拟器 v2 + 域混合加权预埋

## 状态

已接受（2026-09-17，两轮拷问收敛，用户全量确认）。

## 背景

灰度就绪版（P0-P6）完成后，管线全链路验证通过但训练数据仅有合成 + 单剧本模拟器，MAE≈0.0177 虚低；`training_features` 已清空，真实硬件（ESP32-S3）与真实婴儿用户均未到位。PRD 的 MAE 阶梯（W8 1000条<0.30 → W14 5000+<0.18）绑定 Phase 3 真实家庭招募，当前无法直接执行。已知风险：单一硬编码 24h 剧本（设备仅相位错开）有剧本过拟合风险；模拟器样本与真实样本在 `training_features` 中同形（label_source 均为 weak_label/auto_sample），无法区分域。

## 决策

1. **契约冻结**：`feature_spec_version` 保持 1.5.0，本阶段只做同契约增量重训；posture 轴常量修正属硬件到位后的 1.5.1 补丁（维度不变）。
2. **模拟器 v2**：剧本参数化为剧本池（规律型/夜醒频繁型/小睡碎片化型 3 类作息，随机种子生成）+ 设备个性化（hr/motion 基线漂移、佩戴松动/夜间脱落差异）+ 异常场景（哭闹升级、连续夜醒，仅用现有 5 类事件 + sq 波动表达，不引入新事件类型）。剧本池 8:2 切训练/Held-out 池。
3. **域标记零迁移**：`miaowa-model/simulator_devices.txt` 清单文件划分 Domain，不加 DB 列；清单外设备默认 real，真实家庭接入零操作切换。
4. **混合加权预埋**：real 域权重 ×2.0；simulator 域权重 = max(0.3, 1 − 2×real 样本占比)；参数为 `train_xgboost.py` 命令行开关。用 1 台模拟器设备作 Pseudo-real Domain 自测加权逻辑与分层评估报告。
5. **验收口径换锚**：绝对 MAE 降级为回归监控（不许显著劣于上版）；核心门禁改为四项——跨设备留一 MAE、sq 40-70 与 ≥70 分层 MAE 差值、黄金集高分段(>0.7)命中率 ≥60%、**Held-out 剧本测试**（新增核心门禁）。
6. **节奏**：4 周窗口（2026-09-17 起）、每 2 周一版；出口取先到者——硬件产出首批真实数据，或 4 周期满转冷启动待命，不空转训练。
7. **公开数据集**：3 天时间盒调研婴儿 PPG/体动公开数据，只交付结论（PLAN.md 附录），本阶段不接入训练。
8. **后端与 e2e 不动**：改动集中在 miaowa-model/ Python 侧，58 用例 e2e 不新增不回归。

## 后果

- 交付物：`PLAN.md` 下一阶段章节、本 ADR、`CONTEXT.md` 新增 4 术语（Domain / Held-out Script Pool / Pseudo-real Domain / Cold-start SOP）、冷启动 SOP 成稿（W4 末）。
- 飞书《AI模型落地类文档》本阶段不同步（执行层策略不改口径）；真实数据阶段口径实际修订时再同步。
- 备选方案及否决理由：纯等真实数据（窗口空转，否决）；纯模拟器扩量（剧本过拟合无对冲，否决）；本阶段接入公开数据集训练（域差异大、许可不明、收益不确定，降级为调研）；DB 加 domain 列（契约冻结期不必要的迁移，否决）。
- 风险残留：模拟器 v2 的剧本池仍是人工设计的分布，Held-out 剧本与真实婴儿的 gap 无法在本阶段消除，只能延迟到冷启动阶段用真实数据重估。
