# S3 校准报告：picsdb 心率分布 vs 模拟器参数

- 数据：picsdb 1.0.0，10 例早产儿 ICU，有效 5min 窗 9317 个
- 真实 hr_mean 分布：p5=61.596 / p50=74.161 / p95=151.708 bpm
- 真实 hr_std(5min)：p50=3.207 / p95=9.667 bpm
- 真实 hr_trend：p5=-6.6 / p95=6.951 bpm
- 真实 hrv_rmssd：p50=13.765 / p95=59.019 ms
- **心动过缓富集**：hr_mean <100bpm 的窗口占 88%——该库为心动过缓研究采集，中位数被显著拉低，不代表足月家庭婴儿静息心率（文献口径 120~160 bpm）。

## 模拟器 BASE_RANGES 心率区间对照

| 场景 | 模拟器 hr 区间 | 与真实分布的关系 |
|------|---------------|-----------------|
| deep_sleep | 95~105 | 落在真实 p5~p95 包络内 |

## 结论与边界

- picsdb 无场景标注，对照仅为整体包络校验；场景级校准待 Phase C 真实数据。
- 本库为心动过缓研究采集（bradycardia-enriched），绝对中位数不可用；
  模拟器区间（95~146 bpm）落在真实包络内且与足月婴儿文献口径一致，**本轮不调整 BASE_RANGES**。
- ADR-0004 决策 3：本校准只校验模拟器分布先验，不进入训练数据。
